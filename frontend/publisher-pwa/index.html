Cómo funciona

  1. Foto del producto (cámara o galería)
  2. Nombre y precio
  3. Publicar la oferta en WhatsApp

Tip: instala la app para recibir fotos desde WhatsApp con “Compartir”.

Conectar WhatsApp

Comprobando…

Escribe el mismo número de tu WhatsApp (código de país, sin + ni espacios). Ej. Chile: 56912345678.

Luego en el teléfono: WhatsApp → ⋮ o Ajustes → Dispositivos vinculados → Vincular un dispositivo → Vincular con el número de teléfono y escribe el código al momento (caduca rápido).

Si dice que no se puede: quita un dispositivo vinculado viejo, espera 2 minutos y pide un código nuevo.

Este servidor usa WhatsApp Cloud API (número de empresa). No hace falta vincular tu WhatsApp personal.
