Vincular WhatsApp

Como WhatsApp Web, pero con código (sin escanear QR).

  1. Escribe el número de este WhatsApp (con código de país).
  2. Pulsa Obtener código.
  3. En el teléfono: WhatsApp → Dispositivos vinculados → Vincular → Vincular con número.
  4. Escribe el código de 8 caracteres.
